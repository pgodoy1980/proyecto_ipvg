===================================================================
INSTRUCCIONES DE EJECUCIÓN - CHATBOT UNIVERSITARIO (VERSION GROQ + .ENV)
===================================================================

1. Instalar las dependencias del proyecto:
   pip install -r requirements.txt

2. Configurar la clave de la API en el archivo de entorno:
   - Verás un archivo llamado '.env.example'.
   - Renómbralo a '.env' (o crea un archivo nuevo llamado '.env').
   - Abre el archivo '.env' y cambia 'gsk_tu_clave_aqui_...' por tu API Key real de Groq.
   
   *Nota: El archivo '.env' se lee automáticamente por el backend en Python.*

3. Ejecutar el servidor Backend:
   python app.py

4. Abrir el Frontend (debe servirse por HTTP, no con doble clic en el archivo):
   En otra terminal, dentro de la carpeta del proyecto:
   python -m http.server 8080
   Luego abre en el navegador: http://127.0.0.1:8080/index.html

   *Nota CORS: el backend solo acepta peticiones desde orígenes permitidos
   (por defecto localhost/127.0.0.1 en puertos 8000, 8080 y 5500).
   Para agregar otro dominio, define en .env:
   ALLOWED_ORIGINS=http://127.0.0.1:8080,https://tu-dominio.cl
