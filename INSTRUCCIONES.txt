===================================================================
INSTRUCCIONES DE EJECUCIÓN - CHATBOT UNIVERSITARIO (VERSION GROQ + .ENV)
===================================================================

1. Instalar las dependencias del proyecto:
   pip install -r requirements.txt

2. Configurar la clave de la API en el archivo de entorno:
   - Verás un archivo llamado '.env.example'.
   - Renómbralo a '.env' (o crea un archivo nuevo llamado '.env').
   - Abre el archivo '.env' y cambia 'gsk_tu_clave_aqui_...' por tu API Key real de Groq.
   
   *Nota: El archivo '.env' se lee automáticamente por el backend en Python.*

3. Ejecutar el servidor Backend:
   python app.py

4. Abrir el Frontend:
   Simplemente haz doble clic en el archivo 'index.html' para abrirlo en tu navegador.
